9. Accordion

What is event delegation? ▼
Event delegation is a pattern where you add a single event listener to a parent element to handle events for all its children, even those added dynamically.
Why use event delegation? ▼
It improves performance by reducing the number of event listeners, and automatically works with dynamically added elements.
When should I avoid delegation? ▼
Avoid delegation for events that don't bubble (focus, blur) or when you need very specific event handling that's easier to implement directly.
